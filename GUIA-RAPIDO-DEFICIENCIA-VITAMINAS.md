## 📋 Passo a Passo

### 1️⃣ Selecione os Sintomas

**Duas formas de seleção:**

#### A) Por Categoria
- Clique na categoria desejada (ex: "Sono", "Cognitivo")
- Expande mostrando todos os sintomas da categoria
- Clique nos sintomas apresentados pelo paciente
- ✅ Sintoma selecionado fica verde com ✓

#### B) Por Busca
- Digite no campo de busca (ex: "cabelo", "memória")
- Filtra sintomas em tempo real
- Clique para selecionar

### 2️⃣ Visualize os Resultados

**Painel direito mostra automaticamente:**

📊 **Estatísticas**
- Número de sintomas selecionados
- Número de deficiências identificadas

📈 **Tabela de Deficiências**
- Ordenada por prioridade (mais relevante primeiro)
- Cor indica urgência:
  - 🔴 Vermelho: Alta prioridade (≥70%)
  - 🟠 Laranja: Média-alta (50-69%)
  - 🟡 Amarelo: Média (30-49%)
  - 🟢 Verde: Baixa (<30%)

💊 **Dosagens Recomendadas**
- Faixa terapêutica para cada deficiência
- Use como referência inicial

### 3️⃣ Explore os Detalhes

**Expanda as Top 5 deficiências:**
- Clique em cada card para ver mais detalhes
- Lista de sintomas relacionados
- Dosagem específica
- Percentual de relevância

### 4️⃣ Ações Disponíveis

🖨️ **Imprimir**: Gera relatório completo
🗑️ **Limpar Tudo**: Remove todos os sintomas
❌ **Remover Individual**: Clique no X de cada chip

## 📊 Interpretando os Resultados

### Percentual de Relevância

**90-100%**: Deficiência muito provável
- Considerar suplementação imediata
- Solicitar exames confirmatórios

**70-89%**: Deficiência provável
- Avaliar exames laboratoriais
- Iniciar suplementação se confirmado

**50-69%**: Deficiência possível
- Solicitar exames específicos
- Considerar ajustes na dieta

**30-49%**: Deficiência menos provável
- Monitorar sintomas
- Exames se sintomas persistirem

**<30%**: Baixa probabilidade
- Investigar outras causas
- Rever seleção de sintomas

### Priorização

O sistema ordena automaticamente por:
1. **Frequência**: Quantos sintomas relacionados
2. **Relevância**: Percentual de ocorrência
3. **Severidade**: Impacto potencial

## 🔬 Exames Recomendados

Após identificar deficiências prováveis, solicite:

### Para Vitaminas
- **B12**: Dosagem sérica + homocisteína
- **D**: 25-OH Vitamina D
- **B9 (Ácido Fólico)**: Folato sérico
- **A**: Retinol sérico
- **E**: Tocoferol sérico

### Para Minerais
- **Ferro**: Ferritina + ferro sérico + transferrina
- **Magnésio**: Mg sérico + Mg eritrocitário
- **Zinco**: Zinco plasmático
- **Iodo**: Iodúria de 24h
- **Selênio**: Selênio sérico

## 💊 Dosagens - Guia Rápido

### Vitaminas Mais Comuns

| Vitamina | Dosagem Inicial | Manutenção |
|----------|----------------|------------|
| **D** | 5.000-10.000 UI/dia | 2.000-4.000 UI/dia |
| **B12** | 1.000-2.000 mcg/dia | 1.000 mcg/dia |
| **B9** | 400-800 mcg/dia | 400 mcg/dia |
| **C** | 1.000-2.000 mg/dia | 500-1.000 mg/dia |

### Minerais Mais Comuns

| Mineral | Dosagem Inicial | Observações |
|---------|----------------|-------------|
| **Magnésio** | 400-600 mg/dia | Pode causar diarreia |
| **Ferro** | 30-60 mg/dia | Tomar com vitamina C |
| **Zinco** | 15-30 mg/dia | Não exceder 40 mg/dia |
| **Selênio** | 100-200 mcg/dia | Máximo 400 mcg/dia |

## 🎯 Dicas Profissionais

### 1. Seja Específico
- Selecione apenas sintomas realmente presentes
- Evite selecionar todos os sintomas vagos
- Qualidade > Quantidade

### 2. Contextualize
- Considere idade do paciente
- Avalie hábitos alimentares
- Verifique medicações em uso
- Histórico familiar

### 3. Combine Abordagens
- Suplementação + Dieta
- Fitoterapia complementar
- Probióticos se necessário
- Estilo de vida

### 4. Monitore Resultados
- Reavalie sintomas após 30-60 dias
- Solicite novos exames após 90 dias
- Ajuste dosagens conforme resposta
- Documente evolução

## ❓ Troubleshooting

### Problema: Muitas deficiências aparecendo

**Solução**: 
- Revise sintomas selecionados
- Remova sintomas muito genéricos
- Foque nos mais específicos

### Problema: Poucas deficiências

**Solução**:
- Adicione mais sintomas relacionados
- Explore outras categorias
- Considere sintomas subclínicos

### Problema: Resultados inconsistentes

**Solução**:
- Reavalie anamnese
- Considere sintomas secundários
- Solicite exames para confirmar
